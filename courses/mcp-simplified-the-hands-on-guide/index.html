description

About this course

Learn how the Model Context Protocol helps AI applications connect to tools and data, then build and test your own MCP servers through practical examples.

  • Build an MCP server with Python tools, resources, and prompts
  • Test MCP servers with Postman and MCP Inspector
  • Connect an MCP server to an AI agent in VS Code
  • Explore local and remote MCP, JSON-RPC, MCP 2.0, and authorization flows
  • Build an OAuth2-protected MCP workflow with n8n, without writing code

Who this course is for

  • Developers who want to build and test MCP servers
  • Consultants, architects, tech leads, and technical managers exploring MCP
  • Low-code and no-code developers interested in MCP workflows
  • Beginners curious about how AI applications connect to tools and data
